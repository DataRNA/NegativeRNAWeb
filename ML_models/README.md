# Machine-learning models

This directory contains trained machine-learning model artifacts produced by the study workflows. The files cover Decision Tree (DT), Random Forest (RF), Naive Bayes (NB), and Multilayer Perceptron (MLP) models trained with NeRNA, dinucleotide-shuffled, or random-shuffled negative sets.

These files document the analyses and are stored in GitHub. They are not required to run the NeRNA-Web interface and are excluded from the Docker build context.
